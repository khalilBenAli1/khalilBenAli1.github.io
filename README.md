# Khalil Ben Ali — Portfolio

A multilingual Astro portfolio with a progressively loaded Three.js Mediterranean architectural world, an accessible project exhibition, and independent résumé pages. All content remains available in the lightweight view and without JavaScript.

```sh
npm ci
npm run dev
npm run astro -- check
npm run build
npm run test:e2e
npm run preview
```

Use Node22.22+ and npm10.9.8. GitHub Pages deployment remains in the existing workflow and runs the checks before publishing from `main`.

See [scene architecture](docs/island/ARCHITECTURE.md), [asset provenance](docs/island/ASSET_PROVENANCE.md), and [visual QA](design-qa.md). Visual acceptance is tracked independently from functional checks.
